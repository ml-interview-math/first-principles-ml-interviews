# Contributing

Corrections and thoughtful question suggestions are welcome.

## Technical corrections

Please include the exact file or section, the statement or equation you believe is wrong, a concise explanation, and a derivation or reference when useful.

Use the [correction issue template](.github/ISSUE_TEMPLATE/correction.md).

## Question suggestions

A good question for this repo should usually support at least two of:

- a derivation;
- a quantitative estimate;
- an architectural trade-off;
- a systems consequence;
- a meaningful interviewer follow-up.

Use the [question suggestion template](.github/ISSUE_TEMPLATE/question-suggestion.md).

## Confidentiality

Do not submit confidential, proprietary, leaked, or NDA-covered interview questions. General concepts and independently written questions are welcome.

## Style

Prefer precise assumptions and compact derivations over generic explanations. If a claim depends on a convention — FLOP counting, dtype size, batch shape, independence assumptions, or hardware model — state it.
