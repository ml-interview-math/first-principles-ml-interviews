# *Underneath the Surface*

## First-Principles ML & LLM Interview Prep for Frontier Labs

*Underneath the Surface* is a derivation-first interview reference for experienced ML engineers, applied scientists, researchers, and ML systems candidates.

The public repo works one question at a time. The book is the structured curriculum behind those questions.

## What the book covers

- **Streaming linear algebra and matrix calculus** — out-of-core OLS, numerical conditioning, QR vs normal equations, Woodbury, JVPs/VJPs.
- **Classical ML foundations** — objectives, generalization, imbalance, optimizers, metrics, probability, information theory.
- **Autograd and parallel operators** — matrix-multiply backward, softmax-cross-entropy, custom backward operators, associative scans.
- **Transformer mechanics** — attention scaling, MHA FLOPs, causal attention, normalization, SwiGLU, RoPE, KV cache, GQA/MQA, FlashAttention, MoE.
- **Pretraining** — data, tokenization, scaling, optimization, and distributed-training considerations.
- **Post-training** — SFT, policy gradients, PPO, DPO, GRPO, KL control, LoRA/QLoRA.
- **ML systems** — roofline reasoning, prefill vs decode, memory bottlenecks, parallelism, and serving trade-offs.
- **Interview toolkit** — formula sheet, whiteboard answer framework, drills, and study checklist.

## Repo vs. book

| Public GitHub repo | *Underneath the Surface* |
|---|---|
| One question at a time | Structured end-to-end curriculum |
| Focused derivation | Full surrounding theory |
| Selected follow-ups | Broader interview drill set |
| Small reproducible experiments | Integrated math + architecture + systems reference |
| Grows with the daily series | Complete preparation guide |

The repo is not intentionally crippled: each published question should stand on its own. The value of the book is the organization, breadth, and connected treatment across topics.
